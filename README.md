# 🔍 Python Basic Port Scanner

A lightweight and user-friendly Python script to scan open TCP ports on a given IP address within a specified port range. Useful for network diagnostics, security assessments, or educational purposes.

---

## 📦 Features

- ✅ Scans a range of TCP ports on a given IP address
- ✅ Displays only open ports for quick analysis
- ✅ Handles invalid IPs and port ranges gracefully
- ✅ Simple CLI interface
- ✅ Cross-platform (Windows, macOS, Linux)

---

## 🖥️ Requirements

- Python 3.x

No external libraries are required.
